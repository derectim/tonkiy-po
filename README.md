# Тонкий По — сайт кафе, локальный прототип

HTML/CSS/JS без сборки. WordPress и серверная обработка заказов пока не установлены.

## Текущая версия

Первый экран занимает высоту устройства вместе с шапкой. Локальный Manrope используется во всём интерфейсе, читаемый текст — от 14px. Фотография первого экрана и фотографии 29 блюд взяты с действующего сайта кафе. Цены и состав перенесены 15 октября 2026 года. Файлы прежних концептов могут оставаться в assets, но текущий первый экран использует hero.webp.

Доставка/самовывоз и выбор адреса находятся перед меню. Статус открывается в попапе; после оформления внизу экрана появляется постоянная панель заказа. Она работает на телефоне и компьютере, учитывает свою высоту и не перекрывает действия в диалогах. Подвал полностью переработан.

Работают категории, поиск, карточки блюд, избранное, корзина, единое оформление с контактами и деталями адреса, выбор времени, приборов и способа оплаты. В карточке сначала показан плюс, после добавления — счётчик «− количество +». Для вариативных товаров плюс открывает параметры: у каждого варианта свой счётчик, изменения сразу попадают в корзину, общего счётчика внизу нет. Перенесены 12 товаров и 44 комбинации с исходного сайта: лапша и начинка, гарниры, острота, соусы, вкусы напитка. Разные варианты находятся в отдельных строках корзины; их параметры и цены сохраняются в снимке заказа и учитываются при повторе.

Демо-кабинет содержит заказы, детали и повтор заказа по актуальным ценам, сохранённые адреса с редактированием и выбором основного, избранное, профиль и выход. Демо-код входа — 1234; SMS не отправляется. Данные хранятся в браузере на этом устройстве. Сохранён ключ прежней версии pocafe-demo-v1 для переноса корзины и истории.

**Прототип не отправляет заказ в кафе и не принимает деньги.** Статусы меняются вручную в демо-трекере; оплаченным заказ не становится. Доставка и время готовности требуют подтверждения кафе.

## Оплата и запуск в работу

В dist/payment-adapter.js подготовлен отключённый по умолчанию адаптер. Он передаёт на сервер только идентификаторы и количество блюд и данные оформления. Цены и окончательную сумму должен вычислять сервер. Поддержаны ограничения адресов API и платёжного перехода, защита от повторного клика и ключ повторного запроса.

Реальный вход, приём заказов, онлайн-касса, чеки, платёжные уведомления и статусы кухни требуют серверной интеграции. Подробности и схема подключения — в INTEGRATION.md. Платёжный провайдер пользователем пока не выбран.

## Просмотр

Публичный сайт на GitHub Pages: https://derectim.github.io/tonkiy-po/ . Публикация содержимого `dist/` выполняется через `.github/workflows/pages.yml` при изменениях сайта в ветке `main`; возможен и ручной запуск workflow.

Локальный сервер запущен по адресу http://192.168.31.253:5173/ . Доступ зависит от работы этого компьютера и его сети.

Для самостоятельного запуска из корня репозитория нужен Python 3:

```sh
python -m http.server 5173 --bind 0.0.0.0 --directory dist
```

Затем откройте http://localhost:5173/ . Установка зависимостей и сборка не требуются. Для статического хостинга публикуется содержимое `dist/`.

## Дизайн и проверка

Использованы MengTo design-first-ui-prompting и build-awwwards-quality-sites. GSAP/ScrollTrigger и Lenis работают для прокрутки только на десктопе с точным указателем. На телефонах, сенсорных устройствах и экранах до 900px используется нативная прокрутка: изменения высоты браузерных панелей не вызывают ScrollTrigger.refresh. Короткое вступление первого экрана сохранено; при reduced motion анимация отключена. Диалоги и скрытая вкладка останавливают движение десктопа.

Проверены первый экран, меню, кабинет, корзина, оформление и панель статуса на десктопе, узком экране 320px, телефоне и в горизонтальном положении. Автоматические проверки используют только встроенные модули Node.js (версия 20.11 или новее):

```sh
node qa/verify-variants.mjs
node qa/verify-mobile-sections.mjs
node qa/verify-mobile-scroll.mjs
node qa/verify-payment.mjs
```

Снимки экрана и журналы из `qa/`, а также локальные предыдущие варианты из `versions/` исключены из репозитория. Скрипты проверок включены.

Иконки Solar — CC BY 4.0, атрибуция находится в dist/assets/icons. Локальные шрифты — OFL.

Карта кафе открывается в попапе через виджет Яндекс Карт. Актуальная карточка кафе на Архангельской, 15 проверена в Яндекс Картах: https://yandex.ru/maps/org/tonkiy_po/112317817413/ . Виджет открывает именно эту организацию.

Мобильная версия: постоянная навигация по четырём разделам, категории закрепляются под шапкой и следуют за текущим разделом при прокрутке. Нажатие категории переносит к ней внутри полного меню. Карточки компактны (на самых узких телефонах — список), статус заказа находится над навигацией. Кабинет, корзина и оформление открываются как полноэкранные мобильные экраны. Иконки используют локальные SVG Solar; текстовых символов-иконок и emoji нет.

Подготовлены title, description и Restaurant JSON-LD с корректным адресом. В видимом тексте — «Паназиатское кафе в Красногорске», фактический адрес — «Ильинское-Усово, ул. Архангельская, 15». Локальный прототип сохраняет noindex; это не публикация SEO-изменений на действующем pocafe.ru.

Название кафе использует Dela Gothic One с настоящей кириллицей (OFL 1.1, файлы и лицензия в dist/assets/fonts). Название — div, единственный H1 — «Паназиатское кафе в Красногорске». Категория «Популярное» убрана: стартует всё меню. Категории получили 8 разных контурных SVG; семь пищевых пиктограмм авторские, иконка списка — Solar. Интерфейсные подписи и текст остаются в Manrope.

Вариативные товары проверены по свежему публичному HTML pocafe.ru и правилам цен Tilda. Источник и 44 комбинации сохранены в `references/product-variants-source.json`. В исходнике нет публичных ID каждой комбинации или точных остатков: локальные ID получены стабильным хешем ID источника и точных опций, остатки не выдуманы. Старые строки без параметров требуют явного выбора; количество при объединении вариантов не теряется.
