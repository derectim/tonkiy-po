# Тонкий По — концепт нового сайта

Интерактивный прототип для согласования внешнего вида и сценариев заказа. Это самостоятельная витрина на HTML/CSS/JavaScript, а не установленный WordPress.

## Что работает

- 29 блюд с названиями, описаниями, фотографиями и ценами с действующего pocafe.ru на 15 октября 2026 года.
- Категории, поиск, подробности блюда, избранное.
- Корзина с количеством, удалением и пересчётом суммы.
- Доставка / самовывоз, ввод адреса, демонстрационное оформление.
- Трекер с этапами, которые пользователь переключает вручную.
- Демо-кабинет: история, повтор заказа и избранное.
- Сохранение истории и корзины в браузере; адрес — только в текущей сессии.
- Адаптивная версия, локальные фотографии и шрифты, минимум текста 14px.

Два товара с ценой «от» открывают уточнение и контакт кафе: варианты и окончательная цена не выдуманы. Вес и сроки доставки не добавлялись без подтверждения.

## Что нужно для настоящего запуска

Для одного кафе разумная стартовая архитектура — WordPress с собственной темой + WooCommerce и интеграцией с системой кафе. Макет можно перенести в тему; текущий JavaScript нужно заменить серверными корзиной, кабинетом и заказами.

WooCommerce предоставляет кабинет, историю и повтор заказа. Статусы кухни и курьера должны поступать из iiko/r_keeper либо из рабочего интерфейса сотрудников. Нельзя определять их по таймеру. Движение курьера по карте потребует курьерского приложения и его геолокации.

До интеграции нужно узнать, куда сейчас приходят заказы с Tilda и где сотрудники отмечают приготовление/выдачу; затем выбрать схему синхронизации меню, цен, стоп-листа и заказа. Дополнительно подключаются SMS/звонки для входа, эквайринг и подтверждённые правила доставки. Администратору нужны обработка заказов, возвратов и изменений статуса.

## Локальный просмотр

В каталоге проекта: `python -m http.server 5173 --directory dist`. Затем открыть http://localhost:5173 . Установка зависимостей не требуется. Точка входа — dist/index.html.
